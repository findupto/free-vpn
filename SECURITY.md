# Security Policy

## Supported versions

Security fixes are applied to the `main` branch and the latest published release.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed security vulnerability.
Report it privately to the repository maintainers through GitHub's private vulnerability reporting feature when enabled.

Include:

- affected version or commit
- affected platform
- clear reproduction steps
- security impact
- logs or proof-of-concept data with secrets and personal data removed

Please allow reasonable time for triage and remediation before public disclosure.

## Privacy

Do not send VPN credentials, private keys, full configuration files containing credentials, or identifying network data in a report.
